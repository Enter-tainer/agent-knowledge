# 示例索引

> [!note] 📌
> **本页用途：**这是 mock 数据的入口页，用来验证 callout、表格、双链、代码块的渲染。
> **何时读：**本地没有后端、只跑 `pnpm dev` 看 UI 时。
> **可信边界：**内容是为渲染测试编造的，不含任何真实设备信息。

## 读取顺序

1. 先读本页，确认术语与目录约定；
2. 再进 `示例库/`，按设备分目录；
3. 断链与无入链页面见「报告」页。

| 约定 | 说明 | 状态 |
|-|-|-|
| 链接写法 | 只有 `[[文件名]]` 一种，不支持别名与锚点 | 已定 |
| 表格分隔行 | 单横线分隔行（两个及以上短横线） | 已定 |
| callout | 仅 `> [!tip]` / `> [!note]` | 已定 |
| 代码语言 | `powershell` 与 `pwsh` 需归一 | 已定 |

> [!tip] 💡
> 双链只写文件名，不加路径；解析顺序是「同目录优先 → 全库唯一文件名 → 相对路径」。
> 例如 `[[示例设备 B 逆向]]` 会跳到 `示例库/示例设备 B 逆向`。
