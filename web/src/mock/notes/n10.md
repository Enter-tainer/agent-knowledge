# 示例设备 A 逆向

> [!note] 📌
> **本页用途：**mock 总览页。设备画像、显示通路、笔输入结论。
> **可信边界：**全部是编造数据，只用于 UI 自测。

## 结论速览

| 维度 | 结论 | 置信度 |
|-|-|-|
| SoC / 系统 | RK3576 · Android 14 (SDK 34) | 已确认 |
| 显示控制器 | Rockchip EBC，`/dev/ebc`（char 10,243） | 已确认 |
| 笔输入 | `event2` 为 `pen_touch`，压感 10-bit | 已确认 |
| 刷新控制 | per-frame `epd_mode` <br>加系统属性 | 推测 |

## 分区表

| by-name | 物理分区 | 用途 |
|-|-|-|
| `boot` | sda7 | 内核 + ramdisk |
| `super` | sda14 | 动态分区 |
| `waveform` | sda3 | e-ink 波形表 |

## 探测命令

```bash
adb shell getprop ro.build.version.release
adb shell ls -l /dev/ebc
```

```bash
adb shell dumpsys SurfaceFlinger | head -40
```
